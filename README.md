# EDA
Exploratory data analysis (EDA) is a statistical method for analyzing data sets to summarize their main characteristics. It often uses statistical graphics and other data visualization methods.

Here are some types of EDA:
Univariate: Can be non-graphical or graphical 


Multivariate: Can be non-graphical or graphical. Multivariate data comes from more than one variable. 


Bivariate: Visualizes the relationship between two variables. Techniques include scatter plots, correlation, and regression analysis. 

Some other concepts related to EDA include:


Descriptive statistics
A set of methods that summarize and describe the main features of a dataset. Measures like mean, median, mode, and standard deviation are included in descriptive statistics. 


Feature engineering
The process of creating new features or transforming existing features to enhance the predictive power of a model. 


Data visualization
The graphical representation of information and data using visual elements like charts, graphs, and maps.
